# AI Coding Tools Blog

A simple, fast AI tools review blog hosted on Gitee Pages.

## Quick Start

### 1. Create Gitee Repository
1. Go to [gitee.com](https://gitee.com) and login with:
   - Username: `qzw888`
   - Email: `2054164063@qq.com`

2. Click the **+** button → "New Repository"

3. Settings:
   - Repository Name: `aitools-blog`
   - Description: `Best AI Programming Tools Reviews 2026`
   - Choose: **Public**
   - Check: "Initialize this repository with README"

4. Click "Create"

### 2. Push Your Files

Open Git Bash or Command Prompt in this folder and run:

```bash
cd C:\Users\Administrator\Documents\aitools-blog

git init
git add .
git commit -m "Initial commit - AI tools blog"
git remote add origin https://gitee.com/qzw888/aitools-blog.git
git push -u origin master
```

### 3. Enable Gitee Pages

1. Go to your repository: `https://gitee.com/qzw888/aitools-blog`
2. Click **Services** → **Gitee Pages**
3. Click **Enable**
4. Select branch: `master`
5. Click **Deploy**

Your blog will be live at: `https://qzw888.gitee.io/aitools-blog`

## Adding Affiliate Links

Replace `YOUR_AFFILIATE_ID` in the HTML files with your actual affiliate IDs:

1. **Cursor**: Sign up at cursor.sh/affiliate
2. **Replit**: Check Replit's partner program
3. **Others**: Most tools have affiliate programs in their footer

## Updating Content

1. Edit the HTML files locally
2. Run:
```bash
git add .
git commit -m "Update content"
git push
```

Gitee Pages will auto-update within a few minutes.
