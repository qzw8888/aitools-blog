💬 High-Conversion Prompt Templates

🔧 Code Refactoring

Refactor this function to follow clean code principles. Extract reusable helpers, add proper error handling, and add JSDoc comments: [paste code here]
Use when: Code works but is messy, hard to maintain, or needs optimization.

🐛 Bug Finding

Find potential bugs in this code. Look for: null/undefined errors, race conditions, memory leaks, security issues, and edge cases: [paste code here]
Use when: Code has unexpected behavior or you want a security review.

📝 Documentation

Write comprehensive documentation for this code including: purpose, parameters, return value, examples, and any edge cases: [paste code here]
Use when: You need to document a function, module, or API for other developers.

🧪 Test Generation

Write comprehensive unit tests for this function using [Jest / Pytest / etc]. Include happy path, edge cases, and error cases: [paste code here]
Use when: You need test coverage but don't want to write tests manually.

🚀 Feature Development

I'm building a [type of app]. I need a function that does [specific task]. The function should handle [edge cases]. Here's the existing context: [paste related code]
Use when: Building new features — provide context for better output.

💡 Architecture Advice

I have a [type of app] with [description of current structure]. I'm planning to add [new feature]. What's the best approach? Consider: maintainability, performance, and testing. [paste current code or architecture]
Use when: Making architectural decisions — Claude is best for this with 200K context.

⚡ Pro Tips for Maximum Productivity

💡 Do's
✅

Write comments first — describe what you want, then press Ctrl+Enter to generate

✅

Select context — highlight related code before asking AI to improve it

✅

Be specific — "write a React hook" is vague; "write a useDebounce hook that delays by N ms with cleanup" is great

✅

Use .cursorrules — create this file in project root to set AI behavior rules for your codebase

✅

Chain commands — "First write the API, then write tests, then add error handling"

🚫 Don'ts
❌

Don't trust security code blindly — always review AI-generated auth, encryption, and input validation

❌

Don't ignore suggestions — at least read them; AI often catches things you missed

❌

Don't give vague prompts — vague prompts get generic, often wrong code

❌

Don't skip the review — AI is a pair programmer, not a replacement. Always review before committing

❌

Don't use for one-liners — Tab completion handles those; save AI for complex multi-line generation
